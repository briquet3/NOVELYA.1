# Novelya V7.1 — Lectures en cours et thème normal crème

1. Sauvegardez la version actuelle avant de remplacer les fichiers.
2. Sur GitHub, mettez les fichiers du ZIP **directement à la racine du dépôt**, à côté de `index.html` et `app.js` (ne téléversez pas le dossier englobant).
3. Attendez le déploiement Render `Live`, puis faites Ctrl+F5.
4. Les lectures en cours utilisent la table `reading_bookmarks` déjà créée en V6.8. Pour permettre le bouton « Retirer », exécutez **uniquement** `MIGRATION-V7-1-RETRAIT-MARQUEPAGE.sql` dans Supabase SQL Editor.
5. Connectez-vous avec un compte test, ouvrez une histoire, enregistrez un marque-page et vérifiez « Lectures en cours » au-dessus de « Histoires à découvrir ». Le bouton « Reprendre » doit rouvrir la page enregistrée.

Le thème normal devient crème/doré ; Halloween et Noël restent inchangés. Aucun compte, chapitre ou histoire n'est supprimé par ce patch.
